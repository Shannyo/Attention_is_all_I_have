# Градиент (Gradient)

**Короткое определение:** *Вектор из частных производных, который в каждой точке показывает направление самого крутого подъема функции (а с минусом — направление самого быстрого спуска к минимуму ошибки).*

---

### 💡 Бытовая аналогия
Вы стоите на склоне горы в густом тумане и хотите спуститься в самую низкую долину (минимизировать ошибку). Вы не видите всей горы, но можете нащупать ногой уклон земли прямо под собой. **Градиент** — это стрелка компаса, которая показывает строго вверх по самому крутому склону. Чтобы спуститься в долину, нужно сделать шаг в ровно противоположную сторону (**по антиградиенту**).

### 📐 Формальный вид и код
* **Математическое обозначение:** для скалярной [функции потерь](Функция_потерь.md) $\mathcal{L}(\theta)$, зависящей от вектора весов $\theta = (\theta_1, \theta_2, \dots, \theta_n)^T$, градиент обозначается символом набла $\nabla$:
  $$\nabla_\theta \mathcal{L} = \left( \frac{\partial \mathcal{L}}{\partial \theta_1}, \frac{\partial \mathcal{L}}{\partial \theta_2}, \dots, \frac{\partial \mathcal{L}}{\partial \theta_n} \right)^T$$
  Тогда шаг обновления весов: $\theta_{\text{new}} = \theta_{\text{old}} - \eta \nabla_\theta \mathcal{L}$, где $\eta$ — шаг обучения (Learning Rate).
* **В PyTorch:** градиенты вычисляются автоматически вызовом `.backward()` и сохраняются в атрибуте `.grad` каждого обучаемого [тензора](Тензор.md):

```python
import torch

w = torch.tensor([3.0, -4.0], requires_grad=True)
loss = (w ** 2).sum()  # Функция L(w) = w_1^2 + w_2^2, минимум в точке (0, 0)

loss.backward()
print(w.grad)  # Выведет tensor([6., -8.]), так как d(w^2)/dw = 2*w
```
