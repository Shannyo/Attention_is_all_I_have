# Функция потерь (Loss Function)

**Короткое определение:** *Математическая функция, которая сравнивает ответ нейросети с правильным ответом и выдает одно число — «штраф» за ошибку: чем это число ближе к нулю, тем точнее работает модель.*

---

### 💡 Бытовая аналогия
Представьте игру в «горячо — холодно» с завязанными глазами. Сама нейросеть не знает, где спрятан предмет, но после каждого её шага ведущий (функция потерь) называет точное расстояние до цели в метрах. Задача обучения — делать шаги так, чтобы это расстояние уменьшалось до нуля.

### 📐 Формальный вид и код
* **Математическое обозначение:** $\mathcal{L}(\hat{y}, y) \in \mathbb{R}$, где $y$ — истинная разметка (таргет), а $\hat{y} = f_\theta(x)$ — предсказание модели с параметрами $\theta$.
  Например, среднеквадратичная ошибка (MSE) для регрессии:
  $$\mathcal{L}_{\text{MSE}}(\hat{y}, y) = \frac{1}{N} \sum_{i=1}^{N} (\hat{y}_i - y_i)^2$$
* **В PyTorch:**

```python
import torch
import torch.nn as nn

criterion = nn.MSELoss()
y_pred = torch.tensor([2.5, 0.0], requires_grad=True)
y_true = torch.tensor([3.0, -0.5])

loss = criterion(y_pred, y_true)  # Скалярный тензор: ((2.5-3.0)^2 + (0.0 - (-0.5))^2) / 2 = 0.25
loss.backward()                   # Вычисляем градиенты для исправления ошибки
```
