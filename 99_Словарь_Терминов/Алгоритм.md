# Алгоритм (Algorithm)

**Короткое определение:** *Конечный набор однозначных, пошаговых инструкций, который за конечное время переводит исходные данные в искомый результат.*

---

### 💡 Бытовая аналогия
Кулинарный рецепт, где вместо «добавьте соль по вкусу» написано «всыпьте ровно 5 граммов соли, перемешайте ложкой 10 раз по часовой стрелке и нагревайте при 180 °C в течение 12 минут». Исполнителю не нужно уметь готовить или понимать химию процесса — соблюдение шагов гарантирует одинаковый результат.

### 📐 Формальный вид и код
В теории вычислений алгоритм эквивалентен функции переходов $\delta$ [Машины Тьюринга](../01_История_и_Философия_ИИ/01_Колыбель_кибернетики.md), которая отображает входное слово $x \in \Sigma^*$ в выходное $y = f(x)$ за $T(n)$ элементарных шагов.

В классическом программировании алгоритм задается человеком явно, а в машинном обучении алгоритм (нейросеть) сам находит правила преобразования по примерам:

```python
# Классический алгоритм: правило зашито человеком
def is_even_classic(x: int) -> bool:
    return (x % 2) == 0

# ML-подход: алгоритм оптимизации сам подбирает веса под данные
# y_pred = model(x)
```
