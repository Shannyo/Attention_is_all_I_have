## 💡 О проекте

Большинство материалов по искусственному интеллекту впадают в одну из двух крайностей: либо это поверхностный научпоп («нейросеть думает как мозг»), либо сухие академические выкладки, где за матричными дифференциалами теряется физический смысл.

**Attention is all I have** — это открытая энциклопедия и граф знаний, спроектированные так, чтобы одну и ту же тему мог с интересом изучить и человек без технического бэкграунда, и практикующий ML-инженер или исследователь. 

### Принцип «луковицы»: 4 уровня глубины в каждой заметке

Каждая статья в этом репозитории разделена на четыре последовательных слоя погружения. Вы сами выбираете, на каком уровне остановиться сегодня:

* 🟢 **Уровень 0: Интуиция и суть (TL;DR)** — объяснение концепции за 2 минуты на жизненных аналогиях без единой формулы. Позволяет понять, *зачем* технология нужна и *как* она работает в общих чертах.
* 🟡 **Уровень 1: Концепция и архитектура** — визуальные блок-схемы, алгоритмическая логика, входы и выходы системы. Мост между интуицией и строгой теорией.
* 🔴 **Уровень 2: Математический аппарат** — строгий вывод формул, матричные размерности, функции потерь, доказательства и поведение градиентов под капотом.
* ⚫ **Уровень 3: Код и инженерные тонкости** — реализация алгоритма с нуля на чистом NumPy и PyTorch, разбор узких мест по памяти (VRAM), аппаратные трюки и оптимизация инференса.

## 🕸 Как открыть интерактивный граф в Obsidian

Вы можете читать материалы прямо на GitHub, но вся мощь связей раскрывается при локальном открытии хранилища в [Obsidian](https://obsidian.md/):

1. Склонируйте репозиторий:
   ```bash
   git clone [https://github.com/Shannyo/Attention_is_all_I_have.git](https://github.com/Shannyo/Attention_is_all_I_have.git)
   ```
2. Откройте приложение **Obsidian** → нажмите **«Открыть папку как хранилище» (Open folder as vault)** и выберите скачанную папку `Attention_is_all_I_have`.
3. Нажмите `Ctrl + G` (или `Cmd + G`), чтобы открыть глобальный граф знаний. В папке `.obsidian` уже преднастроена цветовая схема узлов по разделам.
